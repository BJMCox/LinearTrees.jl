Getting started

This tutorial fits a regression tree, measures its error on unseen rows, and then fits a binary classifier. It uses only LinearTrees and Julia standard libraries.

Prepare the data

The matrix interface takes a numeric matrix X and a target vector y. Each row corresponds to one target. Keep the feature order the same when predicting.

The example combines a linear trend, a threshold effect, and noise:

using LinearTrees, Random, Statistics

rng = Xoshiro(42)
X = rand(rng, 400, 3)
y = 2 .* X[:, 1] .- X[:, 2] .+ 3 .* (X[:, 3] .> 0.6) .+
    0.1 .* randn(rng, 400)

train, test = 1:300, 301:400
Xtrain, ytrain = X[train, :], y[train]
Xtest, ytest = X[test, :], y[test]
(size(Xtrain), length(ytrain), size(Xtest))
((300, 3), 300, (100, 3))

The rows were sampled independently, so this leaves an independent test sample. For time series or grouped observations, split according to that structure. Fit preprocessing on training rows alone.

Feature values must be finite and numeric at this interface. Encode categorical features as described in Tree fitting, or use the table interface. Handle missing values before fitting.

Fit a regression tree

tree = fit_tree(Xtrain, ytrain; max_depth = 4)
yhat = predict(tree, Xtest)
round.(yhat[1:5]; digits = 3)
5-element Vector{Float64}:
 -0.162
  0.007
  3.939
 -0.056
  3.961

fit_tree uses MSE and BIC by default. BIC balances fit against node complexity. max_depth caps branching depth. A tree may stop earlier when another split does not improve its selection score.

Measure error on unseen rows

Compare the test error with a constant baseline fitted on the same training rows:

rmse = sqrt(mean(abs2, yhat .- ytest))
baseline_rmse = sqrt(mean(abs2, mean(ytrain) .- ytest))
(tree_rmse = round(rmse; digits = 3),
    baseline_rmse = round(baseline_rmse; digits = 3))
(tree_rmse = 0.099, baseline_rmse = 1.655)

Use validation data or cross-validation to choose settings such as max_depth and min_leaf. Reserve the test data for the final assessment.

Fit binary probabilities

The direct binary interface uses targets 0 and 1. Logistic returns the probability of target 1:

probability = inv.(1 .+ exp.(-4 .* (X[:, 1] .- X[:, 2])))
ybinary = Float64.(rand(rng, 400) .< probability)

classifier = fit_tree(Xtrain, ybinary[train], Logistic(); max_depth = 3)
p = predict(classifier, Xtest)
round.(p[1:5]; digits = 3)
5-element Vector{Float64}:
 0.22
 0.422
 0.49
 0.23
 0.816

Choose a threshold when a decision is needed. A threshold of 0.5 is a starting point. Different costs for false positives and false negatives can justify another value.

labels = p .>= 0.5
mean(labels .== ybinary[test])
0.8

For named labels and probability columns with a stored class order, use the classifier wrapper. For more classes, see Loss functions.
